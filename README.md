# Defaults de la organización

Archivos que GitHub aplica por defecto a todos los repositorios de `getmeru` que no tengan el suyo propio:

- `SECURITY.md`: cómo reportar una vulnerabilidad.
- `PULL_REQUEST_TEMPLATE.md`: plantilla de pull request.

Cualquier cambio aquí aplica a todos los repos en cuanto se mergea. Mantiene: Jesús.
